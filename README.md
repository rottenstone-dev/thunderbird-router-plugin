# One Click Forward

Thunderbird add-on to forward emails directly through a dropdown of predefined forwarding configurations.

By David Trapp

Set up forwarding configurations in settings, each with recipients, from identity, forward type, and trash options. Then, use the message toolbar button "Quick Forward" to open a dropdown with your configurations and forward the email with one click. Alt+Click the toolbar button to auto-forward using the first configuration.

If you hold Shift while clicking a configuration, the compose window will stay open without actually sending the email, so you can add further changes before sending it.

## Features

- Multiple forwarding configurations
- Custom from identity per configuration
- Forward as inline or attachment
- Auto-trash after forwarding
- Alt+Click for quick auto-forward with first config
